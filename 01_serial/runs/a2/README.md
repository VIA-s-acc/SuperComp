# Serial, попытка 2

## Что изменено относительно попытки 1

Добавлен **диагональный предобуславливатель** из §5: z = r / D, D = 2/h1² + 2/h2² + Q.
Вместо (r, r) в α и β используется (z, r), новое направление p = z + β·p.
Расчёт Q и F по-прежнему по положению узла.

## Что не так

**w(0,0) по-прежнему отличается от эталона на 4–7·10⁻³.** Предобуславливатель ускоряет
сходимость, но не меняет саму систему уравнений, а ошибка именно в ней: Q_ij и F_ij для
клеток на границе γ берутся по одному узлу вместо доли площади клетки внутри D.
