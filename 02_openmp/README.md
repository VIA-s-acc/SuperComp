## Как распараллелено

Циклы по узлам сетки размечены `#pragma omp parallel for`, строки сетки делятся между нитями.
Скалярные произведения считаются в тех же циклах через `reduction`. Одна итерация метода —
три прохода по сетке. Нити привязаны к ядрам через `GOMP_CPU_AFFINITY` (одна нить на ядро
POWER8), задача занимает узел целиком.

## Результат

Ускорение относительно последовательной программы на IBM Polus: ×12.2 (400×600) и ×15.2
(800×1200) на 16 нитях, ×16.9 на 32 нитях для 800×1200. Решение совпадает с последовательным
на любом числе нитей. 13 тестов (площадь, эталон, точное решение, нити, история итераций)
проходят на Mac и на Polus.
