# Serial, попытка 1

Первая рабочая версия: метод сопряжённых градиентов по §5 и разностная схема (12) на сетке
(M+1)×(N+1).

## Как устроено

- Коэффициенты Q и F из (11) считаются **по положению узла**: если узел (x_i, y_j) лежит в D,
  вся клетка П_ij считается принадлежащей D (F = 1, Q = 0), иначе — фиктивной области
  (F = 0, Q = 1/ε²).
- CG **без предобуславливателя**: z = r, направление p = r + β·p.
- Остановка по (16): ‖w^(k+1) − w^(k)‖_E = |α|·‖p‖_E < δ = 1e-6.

## Прогон на Polus

Задача 1600357, узел polus-c2, `job.lsf`, сетки 20×20, 40×40, 80×80.

| M×N | Итерации | w(0,0) | Эталон: итерации | Эталон: w(0,0) |
|---|---|---|---|---|
| 20×20 | 72 | 0.247280 | 44 | 0.240194 |
| 40×40 | 154 | 0.246574 | 85 | 0.239042 |
| 80×80 | 305 | 0.245359 | 167 | 0.241097 |

## Что не так

1. **Итераций почти вдвое больше эталона.** Без предобуславливателя система плохо обусловлена:
   Q = 1/ε² = 1/h⁴ в фиктивной области (2.6·10⁶ на 80×80) на порядки больше 2/h1² + 2/h2².
2. **Число итераций зависит от машины.** На Mac 72/158/301, на Polus 72/154/305 — плохо
   обусловленный метод чувствителен к ошибкам округления, а они на разных процессорах разные.
3. **w(0,0) отличается от эталона на 4–7·10⁻³** при допуске 2·10⁻³. Клетки, через которые
   проходит дуга окружности, получают Q и F «всё или ничего», граница области ступенчатая.
