# СКМиТ-2026, задание 1, вариант 18

Задача Дирихле для уравнения Пуассона −Δu = 1 в квадрате (−1, 1)² без четверти круга
(x−1)² + (y−1)² ≤ 1, u = sin(x + y) на границе. Метод фиктивных областей, метод сопряжённых
градиентов с диагональным предобуславливателем.

## Структура

| Папка | Этап |
|---|---|
| `01_serial` | последовательная программа |
| `02_openmp` | OpenMP-программа, тесты, таблица 1, отчёт `report/report.pdf` |

В каждой папке `runs/aN/` — попытки: код, LSF-задача, вывод IBM Polus и README с разбором.

## Сборка и запуск

```bash
cd 02_openmp
make                                   # на Polus: make POLUS=1
make test                              # тесты
OMP_NUM_THREADS=4 ./solver 800 1200    # M N [delta]
```

Программа печатает строку `RESULT … iters=… time=… w00=…`. Дополнительные ключи:
`--dump файл` (решение), `--history файл` (история итераций), `--ref файл` (ошибка относительно
эталонного решения), `--exact` (тестовая задача с точным решением u = sin(x + y)).

## Расчёты на IBM Polus

```bash
bsub < 01_serial/job.lsf      # последовательная программа
bsub < 02_openmp/table1.lsf   # таблица 1: serial-база и OpenMP на 2–32 нитях, узел целиком
```

Нити привязываются к ядрам в LSF-файле (`GOMP_CPU_AFFINITY`, одна нить на ядро).

## Таблицы, графики и отчёт

```bash
02_openmp/build_report.sh
```

Строит `02_openmp/results/` (таблица 1, графики ускорения, сходимости и ошибки по итерациям,
рисунки решения) из вывода Polus в `02_openmp/runs/table1/` и собирает `02_openmp/report/report.pdf`.
Нужны Python 3 с `numpy` и `matplotlib` и `xelatex`.
